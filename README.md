# Trabalho_Banco_De_Dados
Controle de almoxarifado e empréstimos do Programa de Educação Tutorial (PET).
É preciso registrar os itens do estoque (equipamentos e componentes), suas categorias, quantidades guardadas e desejadas, além do local físico onde ficam armazenados.
Faz-se necessário controlar as entradas por compra e as saídas por baixa (itens que queimaram, quebraram ou foram consumidos).
Por fim, o sistema deve registrar os empréstimos de itens tanto para membros do grupo (petianos) quanto para discentes externos, permitindo auditar datas de retirada, devolução e quem está com cada material.
